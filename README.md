## 🚀 Features

- 🎯 **Eight Classic & Arcade Games** in one hub
- 🌈 **Stunning UI** with modern Glassmorphism & Dark Mode
- 📱 **Fully Responsive** for all devices
- 🎨 **Beautiful Animations** and interactive effects
- 📊 **Game Stats** tracking

## 🎨 UI Highlights

- **Dark Mode Gaming Theme**: Sleek dark backgrounds with vibrant gradients (`#13151b`).
- **Glassmorphism**: Translucent cards and panels with `backdrop-blur`.
- **Responsive Design**: Works perfectly on mobile, tablet, and desktop.
- **Micro-interactions**: Hover effects, smooth transitions, and feedback animations.
